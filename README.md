## 強み

### 推進と組織統括

入社1年で社内最年少のチーフエンジニアに昇格し、5名のエンジニアチームを統括している。AntigravityやClaude Codeなどの自律型AIエージェントを開発工程に組み込み、プロダクトを市場に出すまでの速度を上げている。

### フルサイクル開発

打ち合わせ、要件定義、DB設計、インフラ、実装、リリースまで一通り担当する。Webに加え、macOSネイティブ、オンデバイスAI、CLI、モバイルアプリ（単独リリース実績あり）も手がける。

### 現場とデジタル

コードだけでなく、オフィスや現場の電気工事・通信ネットワーク配線も自ら施工する。OCRで1,000名規模の病院の定型業務を自動化した。国立津山高専 情報工学科卒。第二種電気工事士 / 工事担任者。
