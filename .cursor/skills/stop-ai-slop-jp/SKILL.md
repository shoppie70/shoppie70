# README向け AI臭除去（薄いポインタ）

本リポジトリは主に日本語のプロフィール README を扱う。文章を直すときは次を参照する。

## 参照元（必読）

1. [iKora128/stop-ai-slop-jp](https://github.com/iKora128/stop-ai-slop-jp) — 書き手の不在・主体・構造・記号
2. [AI臭さを消す日本語スキル、どれが何を直すのか？](https://aimanavo.com/c/akapen_nobu/a/VtZ5sXiIxn4yDQ) — 語彙／書き手／芯の3層とスキルの使い分け

## このリポジトリでの優先修正

1. 見出し・表見出しから装飾絵文字を外す（例: `## 🚀 技術スタック` → `## 技術スタック`）
2. 誇張語を落とす（爆速、最高峰、劇的、極限、ゼロにする、など）。数値は原文にあるものだけ残す。捏造しない
3. 名詞句の見出しにする。「○○は△△だ」型の命題見出しは避ける
4. 事実（役職、技術、プロダクト名・リンク、資格）は変えず、言い回しだけ直す
5. バッジや技術ロゴの shields は残してよい。装飾のためだけの絵文字プレフィックスは外す

## やらないこと

- 新しい実績・数値・製品主張を足す
- プロフィール用の統計ウィジェット（GitHub Stats 等）を「AI臭い」という理由だけで削除する
- 英語の技術固有名詞を無理に日本語へ言い換える
